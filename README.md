# Scrap City Prototype

Build a polished first playable browser prototype of Scrap.io. Create the complete game, not a static mockup. It is a unique .io-style sci-fi scrapyard game where the player controls a small futuristic robot, explores a large neon-industrial city/scrapyard, collects scrap parts, physically attaches components that change stats, encounters AI rival robots, can lose or steal components in encounters, and must reach an extraction zone to win. Include WASD/arrow movement, smooth camera follow, scrap/resource spawning, AI bots, collisions, component types (wheels, battery, armor, magnet, booster, sensor), visible robot customization, inventory/components HUD, minimap, leaderboard, extraction zone, win/lose/restart flow, particles/animations, responsive desktop browser controls, and polished neon-industrial aesthetics. Make it a single-player playable prototype with architecture that can later support multiplayer. Prioritize gameplay and polish over backend multiplayer. App name: Scrap.io.
